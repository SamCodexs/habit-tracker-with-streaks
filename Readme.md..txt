🌱 Habit Tracker with Streaks
A simple and aesthetic Habit Tracker web application that helps users build consistent habits, track their daily progress, and maintain streaks.

✨ Features
- Add and manage daily habits
- Mark habits as completed
- Track daily progress
- Build consistency through streak tracking
- Clean and user-friendly interface

🛠️ Technologies Used
- HTML — Website structure
- CSS — Styling and layout
- JavaScript — Interactive functionality

🚀 How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. Start adding and tracking your habits!
